Seguem as definições de tokens utilizados pelo design system da plataforma Redeprol. Eles são utilizados via _custom properties_ em CSS.

## Tokens primitivos

### Escalas fluídas

Há utilização das escalas fluídas geradas com utilização da ferramenta [Utopia](https://utopia.fyi).

Os tokens de `fluid-scale` são utilizados para espaçamento entre elementos, _padding_, margens, etc. Já aqueles de `fluid-type` são utilizados na tipografia.

As escalas foram geradas com a seguinte configuração dentro da ferramenta:

| | Tela mínima | Tela máxima |
| --- | --- | --- |
| **Largura de tela** | 360px | 1440px |
| **Tamanho de fonte** | 16px | 20px |
| **Escala tipográfica** | 1.125 | 1.125 |

A ferramenta gera valores para os tokens utilizando a função _clamp_, para que os tamanhos se ajustem de forma fluída e gradual a cada tamanho de tela entre os limites estabelecidos.

## Componentes de tipografia

**Cabeçalho _hero_**

```css
.heading-hero {
  /*Texto da seção hero*/
  color: var(--color-heading-hero);
  font-size: var(--font-size-3xl);
  font-weight: var(--font-weight-regular);
  line-height: var(--line-height-large-text);
}
```

**Cabeçalho 1**

```css
.heading-1 {
  /*Títulos de páginas*/
  color: var(--color-heading-primary);
  font-size: var(--font-size-3xl);
  font-weight: var(--font-weight-semibold);
  line-height: var(--line-height-large-text);
}
```

**Cabeçalho 2**
```css
.heading-2 {
  /*Títulos de seções*/
  color: var(--color-heading-secondary);
  font-size: var(--font-size-2xl);
  font-weight: var(--font-weight-semibold);
  line-height: var(--line-height-large-text);
}
```

**Cabeçalho 3**

```css
.heading-3 {

```
